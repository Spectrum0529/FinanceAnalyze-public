# 工作台使用指南 / User guide

第一次使用可先完成[示例](GETTING_STARTED.md)。首页四个入口分别是 **A · 策略与回测**、**B · AI 研究**、**C · 数据管理**、**D · 研究结果**。不明白某项设置时，点旁边的 **? 用法** 查看说明。

## 下载和管理行情

### 下载一份行情

1. 打开 **C · 数据管理 → 新增数据**。没有来源连接时，展开 **新增来源连接**，起一个易认的名字，选择来源并保存。
2. 初次练习可选 **Yahoo 财经（yfinance）**，无需密钥。在 **补充股票代码** 输入 `AAPL`，点 **核对最终范围**。
3. 选择已经过去的日期区间，核对证券名单，点 **开始下载并保存数据**。
4. 完成后到 **我的数据集** 查看名称、证券、实际起止日期和行数。保存的数据可以再次选择，不必每次重新下载。

也可以选择 **本地 CSV 文件**：先预览列与内容，确认日期、代码、价格、成交量对应正确，再导入。来源网站暂时不可用时，先查看原任务状态和失败原因，避免重复提交。

**检查此连接** 不等于下载成功。普通连接检查中，Yahoo 会请求少量行情；其他来源可能只检查本机设置，网络与订阅权限仍显示未验证。独立的小样本请求以页面列出的范围和额度提示为准。

### 查看、回收和恢复

在 **我的数据集** 搜索证券或名称，检查具体版本。暂时不需要的数据可 **移入回收站**。要找回它，切换到回收站，点 **恢复** 或 **恢复为可选数据**。

历史行情的回收操作可能包含它的全部版本，确认框会说明范围。批量操作后查看每一项结果。数据回收不表示重新计算或删除已有报告；报告继续记录原来使用的数据版本。

### 合并两个日期区间

例如，同一来源、同一证券的 2025 年 1–6 月行情，与 4–9 月行情，可以在满足页面规则时合并成覆盖 1–9 月的新版本。

1. 勾选两个标记为可合并的版本，点 **预览合并**。
2. 查看证券、日期、重叠记录和差异。软件会检查格式、价格调整方式以及同一天的记录，不是简单接在文件末尾。
3. 如果提示重新下载完整日期区间，可点 **带入证券和日期**。下载并保存后，在行情列表勾选它，再从 **用于核对全段的行情** 中选中。起止日期都包含在范围内。
4. 再点 **预览合并**。若有价格或成交量修订，读清差异并选择页面允许的处理方式；确认名称后点 **保存合并后的行情**。

普通 CSV、价格基准、本机限定来源及不能核对调整方式的记录，可能不能合并。以预览结果为准；原有版本仍用于追溯以前的报告。

## 数据来源

| 来源 | 需要准备什么 | 使用时注意 |
| --- | --- | --- |
| Yahoo / yfinance | 联网，无需 API 密钥 | 美股和美国 ETF 日线；价格按来源规则调整，不能当作已包含全部现金分红的收益 |
| AKShare | 联网，无需 API 密钥 | 美股与沪深入口的币种、价格处理不同；能下载不代表能用于所有回测 |
| Tushare Pro | 自己的 Token 和对应权限 | 账号权限决定字段、日期范围和额度 |
| Massive | 自己的 API 密钥与套餐 | 可用证券、日期、次数和费用由套餐决定 |
| WRDS | 自己的 WRDS 账号和有效订阅 | 当前股票入口使用 CRSP CIZ；需先核对证券身份，数据及相关报告受本机查看和分享限制 |
| OpenBB 来源 | 已准备好的独立 OpenBB 组件 | 可用来源与组件有关；价格是否调整需看保存的数据说明 |
| CSV 文件 | 有权使用的文件 | 先预览字段和数据；文件导入不会自动证明它适合某种研究 |

回测前核对币种、日期和价格说明。沪深人民币数据不能直接混入只支持美股美元数据的组合回测。今天下载的旧行情也可能经过后来修订；模拟过去时，需要另查当时能看到哪些资料。

## 回测和结果

### 从已保存数据开始

1. 在数据保存完成后的入口开始回测，或打开 **A · 策略与回测**，选择已保存的数据。
2. 选择内置策略，填写虚拟本金、日期和费用。日期留空时，按页面说明使用数据覆盖范围。
3. 核对设置后提交。完成后点击结果或 **查看结果**，打开预览；进一步查看时点 **打开完整报告**。

### 使用自己的策略

在策略中心创建策略与配置，完成实例校验后，点 **用这个策略运行日线回测**。A 页会选中这个实例，再选择行情和费用。

这个日线入口目前限一只证券、最多 256 个实际交易日，支持买入/清仓信号或固定整数目标数量。持仓过程中部分加减仓、外部信号、模型调用等能力不能默认视为支持。策略用当天收盘后的信息决定，订单在下一条实际行情的开盘模拟成交。

### 与一次性买入指数 ETF 比较

先在 C 页保存同一日期区间的 **SPY、QQQ、ASHR**，并按页面要求保存为 **价格基准**（用来与策略比较的行情）。A 页打开 **加入三个指数 ETF**，分别选择保存的版本。

每条对照各用与策略相同的起始本金，在共同起点的开盘买入一次并持有，计入费用和剩余现金；不是把三份本金加到策略账户。报告用不同颜色显示，可分别隐藏或显示。缺少首日或末日行情时，先看原因和实际比较范围。

这些是 ETF 价格对照，现金分红未另计。ASHR 是美国上市、以美元交易的沪深 300 ETF，它的价格与指数本身并不完全相同。

### 找回与管理报告

进入 **D · 研究结果** 搜索记录。点击卡片或按 `Enter` 打开结果预览，按 `Esc` 或 **关闭预览** 回到原位置。可对允许管理的报告 **改名**、**移入回收站**，再从回收站 **恢复**。

恢复报告不会重新下载行情或重新回测。旧报告保留原计算方法和数值，缺少新版明细时会明确显示。先看实际数据范围、费用与曲线，再看文字总结；模拟收益不等于真实成交或未来表现。

## AI 研究与长任务

普通行情下载、内置策略和受支持自建策略的回测不需要 AI 密钥。需要模型参与研究时，先按[模型设置](AI_SETUP_GUIDE.md)配置，再在 B 页选择数据、目标、模型与预算。按页面先看计划，再开始研究。

自主研究需要独立运行组件；页面提示组件不可用时，不能直接开始该功能，已保存结果仍可查看。使用暂停、停止或继续按钮后，等任务状态确认。预算包含已使用的次数和时间，失败或中断不会抹掉先前用量。

想让外部助手代你操作，使用[连接外部 AI](platform/MCP_CONNECTION.md)，不用把登录密码发给助手。

## 显示、存储和缓存

按 `Ctrl+K` 打开显示与工作区设置，可调整主题和动态效果；`Esc` 返回。退出登录、返回工作台和结果预览等辅助按钮继续按页面使用。

在 **设置 → 保存位置** 可以分别指定行情、报告、模型与研究文件的存放目录。先创建文件夹，再粘贴路径并检查。新设置用于之后产生的内容，旧文件不会自动搬家；不要直接删除旧目录。

**计算缓存** 用来复用相同数据和设置的部分计算。清空缓存不等于回收报告；清空后下一次可能需要重新计算，数据库文件也不一定立即缩小。换电脑请用[迁机助手](OPERATIONS.md#迁移到另一台电脑)。

## English navigation

Use **C** for data, **A** for strategies and backtests, **B** for AI research, and **D** for results. Data and result trash actions are reversible through the corresponding lists. Merge preview checks compatible versions; a full-window download may be required to reconcile revised prices. Each ETF comparison uses the same initial capital as a separate alternative account. The [English README](../README.md) covers the first complete workflow.
