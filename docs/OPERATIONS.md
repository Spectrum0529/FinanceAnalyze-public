# 日常维护与换电脑 / Operations

## 打开和停止

打开安装目录中的 `FinanceAnalyze.exe`。工作台准备好后会打开本机网页；需要重新打开时点 **打开工作台**，启动失败时可按提示点 **启动或重试**。关闭网页不等于停止服务，已经开始的任务可以继续运行。

要完全停止，先在工作台确认任务已结束，再点启动器的 **停止服务**，等待停止确认。下次打开时继续使用原账号和保存的数据。

## 修复安装

1. 等待任务结束，点 **停止服务** 并关闭启动器。
2. 使用同一版本的完整安装包打开 Setup。
3. 选择原安装目录，点 **检查并修复**。
4. 完成后重新打开，检查账号、数据和报告。

不要手动删除软件管理的进程记录或复制别处的 Python 环境来“修复”。若提示不能确认正在运行的进程，先检查是否仍有该安装的服务，不要反复启动多个副本。

## 账号与授权

第一次账号通过启动器的 **获取首次设置码** 创建。已有账号从本机网页登录。退出登录使用侧栏或显示设置中的 **退出登录**，它还会结束关联此次登录的外部 AI 授权。

开启双重验证时，先等任务结束并停止服务，在启动器点 **准备双重验证**；重新启动后，到网页账号安全页按提示绑定验证器，并妥善保存恢复码。需要给助手恢复权限时，按[连接指南](platform/MCP_CONNECTION.md)重新授权。

## 备份和恢复

在工作台的 **审计与运维** 页面：

1. 在 **创建备份** 点 **提交备份任务**，等任务完成。
2. 在 **备份状态** 找到记录，复制备份编号。
3. 在 **检查备份或恢复到独立位置** 中先选 **检查备份**，点 **开始所选操作**。
4. 需要查看恢复内容时，选择 **恢复到独立目录**。这一步会建立单独副本，不覆盖现在的工作区。

备份含私人业务记录，请保存在私有位置。密钥和受限原始数据不包含在普通备份中；数据保存在自定义外部目录时，另按来源许可保存需要的内容。不要只复制单个数据库文件而漏掉关联数据或策略包。把恢复副本替换为正在使用的工作区属于维护操作，先确认内容完整并保留原工作区。

## 迁移到另一台电脑

先在目标 Windows 电脑安装 FinanceAnalyze，创建自己的账号；在确认迁入内容可用前，保留旧电脑上的原资料。

1. 旧电脑打开 **设置 → 迁移到另一台电脑**，展开 **在旧电脑准备迁移文件**。
2. 选择页面允许的行情、策略版本或报告，点 **导出所选记录**，保存 `FinanceAnalyze-transfer.json`。
3. 在新电脑登录自己的账号，打开同一页面，选择迁移文件，先查看预览。重复、冲突和不支持的项目会分别说明。
4. 核对后点 **确认迁入这份文件**。Yahoo 行情会在新机重新下载并逐项核对，需要联网；数据被供应商修订时，可能无法与原版本一致。
5. 若仍有未完成项目，查看对应任务后使用 **重查并继续未完成项目**。保持使用同一原文件。
6. 检查 **已保存的迁入记录**，在 D 页打开迁入报告。迁入的策略仍需在新机校验并获准运行。

迁机助手只处理页面明确支持的记录，不会自动迁移所有文件。登录密码、API 密钥、双重验证材料、AI 客户端授权和正在运行的任务不随迁移文件搬过去，需要在新机重新设置。迁入报告保留原内容，不会冒充新机刚运行的回测。

## 常见问题

| 问题 | 先检查什么 |
| --- | --- |
| 网页打不开 | 启动器是否已准备好；是否打开它给出的本机地址 |
| 启动提示组件缺失或版本不符 | 使用原安装包的 **检查并修复** |
| 下载长时间排队 | 在任务页查看状态，并在审计与运维查看后台服务；不要重复提交 |
| 点击后不知道成功没有 | 使用原页面的核对按钮找回原请求，再决定是否重试 |
| 模型不能调用 | 所选连接、对应密钥、模型权限和提供方余额；保存密钥不等于连接成功 |
| AI 助手看不到工具 | [重新加载连接](platform/MCP_CONNECTION.md#已授权但助手没有工具) |
| 移动文件夹后旧数据找不到 | 保存位置设置不自动搬旧文件；恢复原目录或按迁机/恢复流程处理 |

反馈问题时，可提供软件版本、操作步骤和遮去私人内容的提示截图。不要提交密码、密钥、设置码、授权文件、完整备份或私人行情。安全问题只通过仓库实际提供的私密渠道反馈；没有可用私密渠道时，不要在公开问题中贴敏感细节。

## 本机使用边界

账号登录不等于软件已经适合公网部署。本版保持本机访问，不要为远程访问直接开放工作台端口。公开网站或跨网络 MCP 需要另外准备服务器、加密连接、登录和网络防护。

## English summary

Wait for tasks to finish before using **停止服务**. Repair the existing installation with the same release's Setup and **检查并修复**. The operations page can create, verify, and restore backups into a separate location; restoration does not automatically replace the active workspace.

For a new computer, install the app, create your account, and use the transfer assistant. Only supported records are included; credentials and client authorizations must be configured again. Yahoo data is fetched and checked again, so a provider revision may prevent an exact match. Keep the original installation until the transferred records are usable. This release remains local-only.
