FinanceAnalyze Windows launcher

Open FinanceAnalyze.exe to start the local workbench. The default address is
http://127.0.0.1:8000/. Wait until the launcher shows that the workbench is ready.
To stop cleanly, wait for running tasks and use 停止服务.

On a source installation, tools/platform_ops/start.ps1 and stop.ps1 provide
the corresponding PowerShell operations. The launcher verifies the installed
startup files. Use Setup from the same release to repair an installation.
