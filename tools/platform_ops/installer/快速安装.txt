FinanceAnalyze Windows x64

1. 从发行页面下载完整的 Windows 安装 ZIP，再用 Windows 解压到一个目录。如果下载中断，从下载器继续或重新获取同一发行包。
2. 在解压目录双击 FinanceAnalyze-Setup.exe。保留同目录的 FinanceAnalyze.payload.zip，安装器会先核对它的完整性。
3. 点击“安装或继续”。可用默认目录，也可在任意可写的本机固定磁盘上选择空文件夹。安装目录沿用 Windows 的权限设置。准备应用和依赖需要一些时间。
4. 安装完成后点击“打开软件”，以后可打开本机开始菜单的 FinanceAnalyze，或双击安装目录里的 FinanceAnalyze.exe。若系统已存在同名开始菜单入口，安装器保留它。按启动器和网页提示创建本机账号。

安装阶段无需 Git、Python、uv、Node、命令行或网络。
取消后重新打开同一发行包，选择同一目录继续。已完成的安装若需要修复，先停止软件服务并关闭启动器，再在同一发行包选择原目录并点“检查并修复”。修复保留该安装的用户数据。迁机入口按最终版本的使用指南操作，模型及数据服务凭据在目标安装重新配置。

下载体积、磁盘需求及 SHA-256 见发行页。CPython、uv 及依赖声明随安装保留。第三方组件许可随安装包保留。
